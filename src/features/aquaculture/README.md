# 五区车间页面与演示数据

页面与池位分配以用户提供的 `五区取样管路图_A3.pdf` 五页为依据。每页对应一个可切换平面，保留原图车间标题；涉及多栋的标题不扩充为未经确认的单栋页面，也不将五页池数相加声称为全场实际总池数。

| 图纸页 | 页面 | 图示池数 | 检测机与对应池数 |
| --- | --- | ---: | --- |
| 1 | 2-4#～2-6# 贝类育苗区 | 单栋 66 | S1：22；S2：22；S3：22 |
| 2 | 1-9#～1-12# 鱼类育苗区 | 72 | F1：24；F2：24；F3：24 |
| 3 | 2-3# 贝类育种区 | 62 | B1：22；B2：20；B3：20 |
| 4 | 6-1# 鲍鱼车间一层 | 39 | A1：14；A2：25 |
| 5 | 6-1# 鲍鱼车间 42 池平面 | 42 | C1：14；C2：28 |

- 第 1 页注明三栋同型、图示为单栋。第 4 页黑色涂记列仍为待确认点。第 5 页未标楼层，不据此推定为二层。
- `workshops.ts` 统一定义五页标题、数量、设备、原图备注与池框。池框由 PDF 彩色矢量矩形与池号逐个匹配，归一化到 `1100 × 744` 的地图坐标并保留布局比例；不是按统一行列数拼出的占位池。
- 蓝、橙、绿设备分区来自 PDF，分别为 `#165fb1`、`#bd5311`、`#0d8357`。界面沿用原深色大屏背景；点击检测机后，仅其关联池位以对应蓝、橙、绿背景及边框突出，单池选择使用独立亮色框，默认池体保持深色。检测机标记按原 PDF 大圆定位点放置，使用与池框完全相同的缩放与平移；位置不因页面切换、选中状态而挪动。图纸位置不代表已安装点位或现场实测管路。
- `WorkshopDefinition.mapDevices` 保存每台检测机的 `{ id, x, y }`，共 13 个图纸定位点；圆心保持原图对应关系，文字标签可为可读性偏移。
- `getWorkshopPools(id)` 返回独立池布局对象。`Pool.x/y` 为池框左上角，`width/height` 为池框尺寸。`row/position` 保留作列、行索引，其中默认鱼类育苗页兼容旧版十二列六行的通道映射。
- `createDemoSnapshot(now, workshopId)` 仅为当前页面生成对应设备、池号、通道与确定性模拟水质。默认 `workshopId` 为 `fish-nursery`，保留旧版 F1/F2/F3 默认配置。`DEVICE_DEFINITIONS` 仅表示此默认页；其余页面使用各自配置。

# 模拟数值与状态约定

当前未接入现场设备。相同的 `now` 与车间参数得到相同结果；页面刷新生成新快照之前，不会自行改动采集时间。

- 池号由检测机编号与两位通道号组成，例如 `S1-01`、`A2-25`、`C2-28`。各机通道上限以表格为准，不能统一限制为 24。`number` 是当前页内部序号，不替代池号。
- 五项参数为温度、盐度、浊度、pH、溶解氧。示例单位为 ℃、PSU、NTU、无量纲、mg/L；全部实际单位、量程、精度仍需现场确认。
- `METRICS` 中的 `min/max` 与 30 分钟过期阈值是演示设置，不是养殖标准或已确认检测周期。
- 演示设备均显示 `online`，不读取真实连接状态。各页最后三个池演示无数据；内部序号 22–24、49–51（若存在）演示过期；7、14、35、52、61（若存在且有有效采集）演示参数超限。这些状态与现场当前状况无关。
- 状态优先级：无有效值/无采集时间 → `empty`；时间异常/数据过期 → `stale`；部分缺测/超限 → `warning`；其余 → `normal`。缺值为 `null`，显示 `—`，不补 0。`formatMetric` 不附带单位。
- 离线事件时间为快照观察时间，不推断断线时刻。过期池只生成过期提示，不将历史超限当作当前水质报警。
- 历史曲线同为模拟值，保留 `null` 断点并截止于 `measuredAt`，最新点与当前快照一致。无采集时间、未来时间或最后样本在窗口外时返回空数组。五种量纲分别查看。
